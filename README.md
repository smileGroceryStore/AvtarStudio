# 映身 · Avatar Studio 0.8 闭眼与手臂优化

普通摄像头 → 本机 MediaPipe 面部 / 上半身 / 手部追踪 → VRM 角色 → OBS 透明浏览器来源。

## 从源码运行

```powershell
uv sync --extra desktop --group build
npm.cmd ci
.venv/Scripts/python.exe setup_assets.py
npm.cmd run build
.venv/Scripts/python.exe desktop.py
```

模型与追踪权重不提交到 Git；`setup_assets.py` 从来源下载并准备所需目录，模型条款见 `frontend/public/assets/models/LICENSE-SOURCES.txt`。源码不包含个人导入的角色。

挂件只有按住角色可见部分才能拖动，透明空白处不触发拖动。3D 按当前渲染像素透明度判断，2D 按实际 SVG 形状判断；选中角色后拖出轮廓仍会继续移动。

## Windows 桌面版

安装版：运行 `installers/AvatarStudio-0.8.0-Windows-x64-Setup.exe`，支持 Windows 10 / 11 x64。默认安装到当前用户的 Programs 目录，无需管理员权限；可选择桌面快捷方式，在系统「已安装的应用」中卸载。升级与卸载保留个人模型和设置。

安装包构建：安装 Inno Setup 6 后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File build-installer.ps1`；添加 `-RebuildDesktop` 可先重新构建程序，或用 `-Compiler` 指定 ISCC.exe。SHA256 校验文件与安装说明生成在同一目录。

安装往返测试：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-installer.ps1`，在 test-results 下安装、检查文件、执行桌面烟雾测试再卸载，不改动个人模型和参数。

双击 **启动桌面版.cmd**，或直接运行 **release-layout/AvatarStudio/AvatarStudio.exe**。

- 独立 Windows 窗口，不需要手动启动终端或浏览器。
- 绿色目录版：复制时请保留整个 `AvatarStudio` 文件夹及其中的 `_internal`，不能只复制 EXE。
- 已包含 Python、追踪模型及页面资源，使用时不需要安装 Python、Node.js 或联网下载依赖。
- 使用系统 Microsoft Edge WebView2 Runtime。当前笔记本已安装；其他电脑缺少时需先安装微软官方运行时。
- 关闭或最小化控制台会隐藏窗口，系统托盘保留软件并继续处理已开启的捕捉。双击托盘图标恢复控制台，右键可显示挂件、隐藏全部窗口或退出。点击托盘菜单或角色上的“退出”停止软件并释放摄像头。
- 皮套和参数保存在 `%LOCALAPPDATA%/AvatarStudio`，升级软件不会覆盖。首次在本工作目录启动会迁移旧版 `data/` 中的模型和参数，不复制摄像头画面。
- 点击“复制 OBS 地址”取得当前桌面实例的输出地址。默认使用 8080；端口被占用时自动选择可用端口。

### 分组工作区与衣物避让

左侧通过「捕捉 / 角色」、右侧通过「动作 / 画面 / 输出」切换设置；低频工具收起展示。网页、窗口和托盘采用同一圆角线条标识。动作页新增可关闭的「衣物避让」，仅对贴近躯干、向下垂的上臂增加少量外侧空间，减少袖口和身体相交；不提供完整布料碰撞模拟，宽袖与裙摆仍依赖模型的蒙皮及物理配置。

### 简约深色界面

主界面使用石墨灰底色与少量青绿色强调，移除雷达、扫描线与发光边角。摄像头和捕捉操作置于设置上方；挂件、系统托盘右键菜单共用深色主题，保留键盘选择、勾选和禁用状态。

### 0.4 桌面挂件与动作协调

双击 **启动桌面挂件.cmd**，或者在控制台点击 **挂到桌面 / 仅显示挂件**。挂件透明、无边框、默认置顶，共用当前皮套与摄像头追踪。拖动角色可以移动；右键打开设置、捕捉、缩小、放大、置顶、收起及退出菜单。挂件位置、尺寸与置顶选项保存于 `%LOCALAPPDATA%/AvatarStudio/widget.json`。

角色采用独立全身构图，不受控制台裁切和画面高度影响。腿部保持模型自然站姿，当前不提供单摄像头腿部动捕。

动作映射改为根据模型真实骨骼方向、身体父关节和已平滑的上臂计算前臂方向，减少身体旋转和手臂旋转的重复叠加。手腕去除强制翻转偏移，并限制扭转角度。若旧设置的平滑过高，可以点击“应用自然跟随参数”恢复为 40% 平滑。

### 0.3 科幻 HUD 界面

按用户提供的科幻 HUD 参考重设界面：深空蓝、青色发光边框、L 型锁定角标、雷达扫描和状态脉冲。包含减少动画模式及移动布局。窗口标题栏和图标同步采用深色 HUD 风格；帧率与推理耗时使用实际数据。OBS 输出保持透明。

### 0.2 动作优化

- 修正 MediaPipe 世界坐标 Y 方向，避免抬手、放手映射反向。
- 区分 VRM 0.x / 1.0 骨架朝向，统一局部关节旋转，使同一动作在两种模型上保持一致。
- 手腕、手肘置信度低或出画时让对应手臂回到放松姿态，避免跟随推测坐标乱动。
- 手指加入自适应滤波，手腕扭转按圆周滤波，检测丢失时清理历史值。
- 手臂待机姿态更放松，减少逐帧渲染中的临时对象分配。
- 真人监看关闭时跳过画面标注和 JPEG 编码，开启时限制为 15 fps，减少 CPU 开销。
- 新增“聊天 / 半身 / 互动”快捷模式：聊天只捕捉脸部，半身加上身体，互动再加手指。

单摄像头仍无法准确识别完全遮挡的动作。实际跟随效果取决于取景、光照和模型骨骼；建议先用“半身”模式校准，再尝试“互动”。

## 使用顺序

1. 示例角色会自动加载，或者导入自己的 `.vrm`（VRM 0.x / 1.0，最大 100 MB）。切换角色前先停止捕捉。
2. 默认设备编号为 0。摄像头打不开时关闭其他占用摄像头的软件，或尝试 1、2 等编号；编号由 OpenCV 枚举，不是设备名称。
3. 点击开始，正对镜头保持自然表情约 1 秒完成自动校准。之后可以眨眼、转头、张嘴、抬手。
4. 打开“显示真人画面”，可在本机检查取景和追踪点；默认隐藏。监看不会显示到 OBS 输出。
5. 用灵敏度、表情强度、平滑程度调整跟随效果；缩放与高度调整构图。设置自动保存在 `data/settings.json`，导入角色保存在 `data/avatar.vrm`。
6. 改变坐姿或摄像头位置后重新校准。

## OBS

添加 **浏览器来源**，地址 `http://127.0.0.1:8080/output`，尺寸 **1280 × 720**，帧率 **30**。保留 OBS 默认的透明背景 CSS。

工作台和 OBS 共享后台追踪、角色与参数。输出页只有角色，不含真人画面、控制面板或状态文字；断线或角色加载失败时会显示错误提示。输出始终透明，不受工作台背景选项影响。预览舞台与 OBS 宽高比不同，裁切会有差异，最后以输出页为准。

## 形象修改

第一版支持导入和切换 VRM，不包含软件内捏脸或换装。使用 VRoid Studio 修改脸型、发型、衣服后重新导出 `.vrm` 并导入。模型需有人形骨骼；眨眼、嘴型和表情效果取决于模型有没有相应的表情绑定。单张立绘 / PNG 不能直接作为可动 VRM。

## 范围和限制

- 面部转向、眨眼、嘴型、基础表情，上半身、手臂及手指跟随。
- 第一版不驱动腿部、不提供专业全身动捕或虚拟摄像头设备；通过 OBS 浏览器来源直播。
- 遮挡、侧脸、出画、快速动作会影响准确度，手部需要进入镜头，光照需均匀。
- 工作台只监听 `127.0.0.1:8080`，不将视频或追踪结果发到外部。推理模型、JS 依赖与示例皮套的首次下载需要联网。
- 服务不录制视频。导入模型和参数会保存到本机，日志保存在 `data/`。
- 若端口 8080 已被其他程序占用，先关闭占用程序；错误信息见 `data/server-error.log`。

### 2D 猫耳伙伴
控制台“形象模式”可切换 3D VRM / 内置 2D 角色。2D 支持头部、眨眼、张嘴与双臂方向跟随，提供薄荷青、樱花粉和冰川蓝配色，支持透明 OBS 输出和桌面挂件。这是原创 SVG 分层角色，暂不支持导入 Live2D/Cubism 模型。

### 0.5 后台运行
控制台点击“转入后台 · 系统托盘”隐藏全部窗口，已开启的动捕和 OBS 输出继续运行。Windows 任务栏右下角（可能在“^”隐藏图标中）的映身图标支持双击恢复、右键显示控制台、显示桌面挂件、后台运行与退出。也可双击“后台运行.cmd”或执行 `AvatarStudio.exe --background` 直接启动到托盘。摄像头仍需点击“开始捕捉”开启。后台运行不等同于关闭电脑后的服务。

### 0.6 纯净挂件
挂件不显示文字、工具条或错误框。左键按住角色拖动，右键打开 Windows 原生菜单；捕捉状态和错误在控制台查看。系统托盘功能保持可用。

### 0.7 第一轮动捕优化
脸、姿态和手部在独立线程上处理同一最新画面，每个模型每次只处理一帧，未开启的模型不运行。手臂使用统一的自适应方向滤波和稳定骨长；丢失追踪最多保持 120 ms，随后平滑放松；单帧大幅反转需要下一帧确认。2D/3D 共用稳定后的手臂数据。加快头部大动作与眨眼跟随，保留用户现有参数。
控制台显示驱动读取帧率、各模型耗时和采集后处理时间。采集后处理时间不含曝光、驱动缓冲、网络与屏幕延迟，不能视作端到端延迟。纯净挂件保持无文字。
本机公开 portrait 图片预热后 20 次对比：脸+身体顺序 43.77 ms / 并行 32.30 ms；含手部顺序 81.42 ms / 并行 53.48 ms。这是离线识别调度测试，不代表真人动作精度或保证实际摄像头帧率。在项目根目录运行 `.venv/Scripts/python.exe tests/bench_motion.py` 可重测。

### 0.8 闭眼与手臂
闭眼使用独立开眼基准、眼睑三维开合比例与快速闭合/睁开迟滞，避免校准均值和普通表情平滑压低短促眨眼。普通表情强度不再缩小闭眼幅度；支持独立闭眼灵敏度 0.8–1.8。VRM 仅有通用闭眼形变或空的左右闭眼定义时回退通用通道，避免重复叠加。2D 闭眼显示眼睑曲线。
右键“测试闭眼（1秒）”在不打开摄像头的情况下驱动所有输出；测试成功表示模型闭眼通道可用。控制台可看左右闭眼信号，并单独调闭眼灵敏度；校准时请睁眼、正对镜头。
手臂增加最大 160 度屈肘约束，避免估计反转使前臂折回肩部。仍不提供腿部跟随，腿保持站姿。

髋部出画或置信度不足时不推算身体前倾；限制躯干倾斜，避免半身取景的髋部误估牵动上半身。

0.8 姿态调整：2D/3D 默认上臂贴近躯干，肘部约弯曲 28 度，手部略朝前并收拢；未追踪手指轻微弯曲。丢失手臂时缓慢回到放松姿态，保留有效动捕的响应速度。

## 本机动漫与游戏角色

个人模型存放在 `%LOCALAPPDATA%/AvatarStudio/library`，不打包进通用发行版；`catalog.json` 登记 id/name/file/notice，主窗口角色库会自动读取。当前本机添加初音未来 V4X（没有面部表情绑定，只支持头身/手臂跟随）与哥伦比娅转换版（带闭眼绑定）。来源与用途说明保存在该目录 SOURCES.txt。当前桌面启动入口使用 release-anime。

长发物理：保留模型自带 Spring Bone；对完全没有物理配置且头部下有长单链骨骼的模型补充弹簧，保持发根固定。当前初音双马尾补充 14 个动态关节。3D 俯仰映射已修正抬头/低头方向。

## 待机姿势与动作



手腕动捕：由掌指关节构建完整三维掌面，使用实际模型的手指根部建立基准，前臂完成转动后求解手腕世界朝向；绕过旧单轴角度滤波与 ±40° 限制，手腕使用独立快速四元数平滑。单目摄像头遮挡、手掌侧向时仍取决于 MediaPipe 跟踪质量。

当前待机动作仅保留自然下垂、轻松摇摆（动态），由用户手动选择并保存。旧版本已删除的姿势设置自动恢复自然下垂。

手腕自然模式：掌面方向继续用于跟随，但跟随幅度降低；手腕弯折限制约 30°、扭转约 60°，角速度限制约 149°/秒，并使用更温和的平滑。优先避免手腕反折和瞬间翻转。

手腕跟随已恢复正常动作 1:1 幅度，放宽到弯折约 80°、扭转约 150°；仅对超过约 115° 的突然变化确认 50ms，忽略单帧翻转，连续动作继续跟随。

手臂与手腕协调：手部检测按图像手腕位置匹配 Pose 的左右腕（含交叉手），无有效身体腕点时按未镜像输入纠正手部标签。前臂分担翻掌旋转，手腕处理剩余朝向；异常跳变在世界空间判断，避免把前臂运动误判成翻掌跳动。当前腿部仍保持站姿，未接入腿部动捕。

关节约束更新：前臂轴向旋转限制 ±85°，手腕额外轴向旋转 ±35°；手腕屈伸与侧弯分开约束（分别约 70° / 25°）。修复掌面跨界时角度累计成多圈、回正后不复位的问题。以上为软件动画约束，并非个人关节活动范围测量。
