# 映身 HUD / 0.3

依据用户提供的 STYLEKIT 科幻 HUD 参考。

- 背景 #020617；面板 rgba(15,23,42,.85)；青色 #06b6d4 / #22d3ee；辅助蓝 #0ea5e9。
- 主文字 #e5f2ff，辅助文字 #94a3b8。Consolas / Cascadia Code 等宽字体配中文无衬线回退。
- 面板 2–3px 小圆角、L 型角标、青色内发光；不使用浅色底、大圆角、普通投影或暖色装饰。
- 状态脉冲 2s、雷达旋转 6s；悬停时角标收缩与扫描线增强；按下反馈使用内发光。
- prefers-reduced-motion 时关闭装饰动画，保留清晰的静态状态、焦点与文字提示。
- 帧率和推理耗时读取实际后端数据；不添加模拟 CPU、网络或设备状态。
- OBS 纯净输出保持透明，无网格、扫描线、HUD 和控制面板。
- 品牌、favicon、PNG、ICO、EXE 与原生窗口图标均来自 frontend/app-icon.svg。
