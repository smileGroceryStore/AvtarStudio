映身 · Avatar Studio 0.8 闭眼与手臂优化

启动：双击 AvatarStudio.exe。
请保留同目录的 _internal 文件夹；复制软件时请复制整个文件夹。

摄像头：点击“开始捕捉”后才开启，关闭或最小化控制台会转入系统托盘，已开启的捕捉继续运行；右键托盘图标点击“退出映身”或角色旁点击“退出”停止软件。
首次请保持自然表情、正对镜头校准；建议先选“半身”模式体验动作。
换皮套：停止捕捉后，点击“导入我的皮套”，选择 .vrm。
OBS：点击“复制 OBS 地址”，添加到 OBS 的浏览器来源，尺寸 1280×720。

数据及日志：%LOCALAPPDATA%\AvatarStudio
Windows 需有 Microsoft Edge WebView2 Runtime（本机已安装）。
摄像头画面在本机处理，不上传，不录制。

动作优化：
- 修正手臂上下方向及 VRM 0 / 1 坐标差异。
- 过滤出画或低置信度的手臂，改善手指与手腕抖动。
- 真人监看关闭时不进行预览画面的绘制与编码。

内置模型：VRoid Project / hinzka，遵循各自模型授权。
追踪代码基于 DarkStar1997/vtubing（MIT），授权见 _internal/UPSTREAM-LICENSE。
其他第三方依赖遵循各自授权；详见 THIRD-PARTY-NOTICES.txt。

0.3 新界面：深空蓝与青色 HUD，统一取景框面甲图标；支持减少动画设置，OBS 仍为透明输出。

桌面挂件：控制台点击“挂到桌面”，或使用启动桌面挂件.cmd。
拖动角色移动，右键可设置、捕捉、缩放、置顶、收起或退出。
当前腿部保持站姿，仅跟随头部、上半身与手部。

2D 模式：角色控制台 → 形象模式 → 2D 猫耳伙伴，可换三种配色，支持表情、双臂跟随和透明挂件。目前不支持 Live2D 文件导入。

挂件只显示角色，按住角色拖动，松开后保存位置。右键打开捕捉、配置、缩放与退出菜单，追踪状态和错误在控制台查看。

修复版：透明窗口由 DWM 合成，接收鼠标并支持拖动；2D 跟随肩、肘、腕坐标，根据前后深度切换身体前后遮挡。

后台运行：控制台点击“转入后台 · 系统托盘”，或双击“后台运行.cmd”直接隐藏启动。双击任务栏右下角映身图标恢复控制台（可能收纳在 ^ 内），右键可显示挂件或退出。

0.7 动捕：并行识别；手臂自适应滤波、稳定骨长、120ms 短暂丢失保持；加快眨眼跟随。控制台可查看相机读取帧率及处理耗时。

0.8：右键角色→测试闭眼（1秒），无需摄像头即可验证模型。控制台独立调闭眼灵敏度、查看闭眼信号；睁眼正对镜头校准。手臂新增屈肘约束，腿仍保持站姿。

半身取景：髋部不可见时不再推算身体前倾，减少躯干误估影响手臂。
