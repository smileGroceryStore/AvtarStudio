映身 · Avatar Studio 0.8

适用系统：Windows 10 / 11，64 位。
安装包含程序、追踪模型和内置角色，无需安装 Python 或 Node.js。
需要 Microsoft Edge WebView2 Runtime；多数 Windows 10 / 11 电脑已安装。
如打开程序提示缺少 WebView2，可从微软官网安装：
https://developer.microsoft.com/microsoft-edge/webview2/

安装后双击桌面“映身”图标。
左侧选择“角色”导入 VRM，或选择内置角色；在“捕捉”页点击“开始捕捉”。
右侧“动作 / 画面 / 输出”调整跟随、构图和 OBS 透明输出。
“挂到桌面”显示透明角色，拖动角色可移动，右键打开设置；透明空白区域的鼠标事件透传到后面的窗口。
关闭或最小化设置窗口后软件保留在托盘，右键托盘可退出。

模型、参数和日志保存在：%LOCALAPPDATA%\AvatarStudio
升级或卸载软件会保留此目录，方便再次安装使用。
摄像头仅在手动开始捕捉后开启，画面在本机处理。
衣物避让为轻量姿态调整，宽袖、裙摆仍依赖模型权重及物理配置。

内置模型及依赖授权见安装目录中的 THIRD-PARTY-NOTICES.txt。
个人导入的模型不会随安装包分发。
